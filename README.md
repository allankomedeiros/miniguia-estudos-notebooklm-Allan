# Miniguia-estudos-notebooklm-Allan
Repositório criado para o desafio prático da Dio.me de exploção do poder do NotebookLM

### Contexto e Objetivos

Este projeto foi desenvolvido como parte de um desafio prático da DIO com o objetivo de explorar o uso da Inteligência Artificial como ferramenta de aprendizado ativo.

O tema escolhido foi **Governança no Microsoft Azure**, com foco em:

- Resource Groups
- RBAC (Role-Based Access Control)
- Azure Policies

### Objetivos de estudo:
- Compreender os conceitos fundamentais de governança em cloud
- Consolidar conhecimentos para a certificação AZ-104
- Aprender a utilizar IA (NotebookLM) para estudo estruturado
- Criar um material reutilizável para revisões futuras

## Miniguia de Estudo

### Resource Groups
- Container lógico para recursos
- Permite gerenciamento conjunto
- Base para organização no Azure

### RBAC
- Controle de acesso baseado em função
- Define quem pode fazer o quê
- Exemplo: Owner, Contributor, Reader


### Azure Policy
- Garante conformidade
- Impõe regras nos recursos
- Exemplo: exigir tags obrigatórias



### Glossário

- RBAC: Controle de acesso baseado em funções
- Policy: Regra de governança
- Resource Group: Agrupador de recursos
- Subscription: Conta de cobrança e controle
